How to train

  1. Wait for the camera to load and the status to say Ready!
  2. Type a class name in the text box (e.g. library_entrance)
  3. Point the camera at the object or location
  4. Click Add Sample repeatedly from different angles (aim for at least 20 samples per class)
  5. Change the class name and repeat for each object or location you want to add
  6. Once all classes have enough samples, click Train & Save
  7. Wait for training to complete — the status will say Saved! when done

Tips: vary your distance and angle for each sample. More samples = better accuracy.
